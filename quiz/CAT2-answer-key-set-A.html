#TypeAnsExplanation / Model Answer
1MCQDCompile is a software translation step, not a hardware instruction-cycle phase. The phases are: Fetch, Decode, Execute (and optionally Memory access, Write-back).
2MCQBBig Endian stores the MSB at the lowest memory address.
3MCQBIn programmed I/O, the CPU continuously polls the device status (busy-waiting) until the transfer completes.
4Short—MIPS = Million Instructions Per Second. Formula: MIPS = Instruction Count / (Execution Time × 106), or equivalently MIPS = Clock Rate / (CPI × 106).
5MCQCFully associative mapping allows a block to be placed in any available cache line.
6MCQAProgrammed I/O keeps the CPU busiest — it is stuck in a polling loop for the entire transfer. DMA frees the CPU the most.
7MCQCRegisters are the fastest and smallest memory in the hierarchy.
8MCQCFIFO may suffer from Belady's anomaly — increasing cache size can paradoxically increase the miss rate.
9MCQBInterrupt-driven I/O lets the CPU do other work; the device sends an interrupt when ready.
10Short—ALU functions: Arithmetic operations (add, subtract, multiply, divide), Logic operations (AND, OR, NOT, XOR), Shift operations, Comparison operations.
11MCQADirect mapping: Cache line = Block address MOD Number of cache lines.
12MCQBCycle stealing — the DMA controller borrows bus cycles from the CPU to transfer data.
13Short—Little Endian stores LSB first: Addr 100 = BE, Addr 101 = BA, Addr 102 = FE, Addr 103 = CA.
14MCQBWrite-back updates main memory only when the dirty cache line is evicted/replaced.
15MCQBStrobe uses a single control line activated by either source or destination to signal data validity.
16MCQCMIPS = 2×108 / (0.5 × 106) = 400 MIPS.
17MCQB16 lines / 4-way = 4 sets.
18Short—DMA is a technique where a dedicated controller transfers data directly between I/O devices and main memory without continuous CPU involvement. Advantage: frees the CPU to perform other tasks during transfer.
19MCQBMicroprogrammed control unit generates signals from microinstructions stored in control memory (ROM).
20Short—Look-aside: Tavg = h × TC + (1−h) × TM = 0.95 × 10 + 0.05 × 100 = 9.5 + 5 = 14.5 ns.
21MCQBBuffering temporarily stores data to compensate for speed differences between devices.
22Short—PA = log2(256) = 8 bits. Offset = log2(8) = 3 bits. Lines = 64/8 = 8 → Index = log2(8) = 3 bits. Tag = 8 − 3 − 3 = 2 tag, 3 index, 3 offset.
23Short—Ref: 1,2,3,4,1,2 on 3 lines (FIFO):
1→[1,-,-] Miss | 2→[1,2,-] Miss | 3→[1,2,3] Miss | 4→[4,2,3] Miss (evict 1) | 1→[4,1,3] Miss (evict 2) | 2→[4,1,2] Miss (evict 3). Hits = 0, Misses = 6.
24Short—Handshaking uses two control signals. Sender asserts "data valid"; receiver reads data and asserts "acknowledge"; sender de-asserts its signal; receiver de-asserts acknowledge. This four-step protocol ensures reliable transfer regardless of device speed differences.
25Short—Three Cs: (1) Compulsory (cold) — first access to a block, unavoidable. (2) Conflict (collision) — multiple blocks compete for the same line/set. (3) Capacity — cache too small to hold all needed blocks.
26MCQBLook-through: Tavg = TC + (1−h) × TM. Cache is checked first; on miss, memory is accessed after.
27Short—Programmed I/O: CPU busy-waits (polls device status continuously) — wastes CPU cycles. Interrupt-driven I/O: CPU executes other instructions and is interrupted only when device is ready — much better CPU efficiency.
28MCQBHardwired control uses combinational logic circuits and state machines (not stored microinstructions).
29MCQBLow-order interleaving places consecutive addresses in different memory modules (round-robin).
30Short—Any three: Control and timing of data transfer, Communication with the CPU, Communication with external devices, Data buffering, Error detection.
