1MCQBLow-order interleaving places consecutive addresses in different memory modules.
2Short—ALU functions: Arithmetic (add, subtract, multiply, divide), Logic (AND, OR, NOT, XOR), Shift, Comparison operations.
3Short—Three Cs: (1) Compulsory (cold) — first access. (2) Conflict (collision) — blocks compete for same line/set. (3) Capacity — cache too small.
4MCQBStrobe uses a single control line activated by either source or destination.
5Short—PA = 8 bits, Offset = 3, Index = 3, Tag = 2. (See Set A Q22.)
6Short—MIPS = Instruction Count / (Execution Time × 106).
7MCQBCycle stealing — DMA controller borrows bus cycles from CPU.
8MCQBBig Endian stores MSB at the lowest address.
9Short—FIFO trace: 1,2,3,4,1,2 → Hits = 0, Misses = 6. (See Set A Q23.)
10MCQDCompile is a software step, not an instruction-cycle phase.
11Short—DMA transfers data directly between I/O and memory without continuous CPU involvement. Advantage: frees CPU.
12MCQB16 lines / 4-way = 4 sets.
13MCQBBuffering compensates for speed differences between devices.
14MCQBMicroprogrammed control uses microinstructions in control memory (ROM).
15MCQBLook-through: Tavg = TC + (1−h) × TM.
16Short—Little Endian: Addr 100 = BE, 101 = BA, 102 = FE, 103 = CA.
17MCQAProgrammed I/O keeps CPU busiest — stuck polling the entire transfer.
18MCQCMIPS = 2×108 / (0.5 × 106) = 400.
19Short—Any three: Control/timing, CPU communication, device communication, data buffering, error detection.
20MCQCFully associative: block can go in any available cache line.
21Short—Look-aside: 0.95 × 10 + 0.05 × 100 = 14.5 ns.
22MCQBHardwired control uses combinational logic and state machines.
23Short—Handshaking: sender asserts "data valid" → receiver reads and asserts "acknowledge" → sender de-asserts → receiver de-asserts. Four-step protocol for reliable transfer.
24MCQCFIFO may suffer from Belady's anomaly.
25Short—Programmed I/O: CPU busy-waits, wastes cycles. Interrupt-driven: CPU does other work, interrupted when device ready — much better efficiency.
26MCQCRegisters are fastest and smallest in the memory hierarchy.
27MCQBProgrammed I/O: CPU continuously checks device status (busy-waiting).
28MCQBWrite-back updates main memory only when dirty line is evicted.
29MCQADirect mapping: Cache line = Block address MOD Number of cache lines.
30MCQBInterrupt-driven I/O: CPU does other tasks, notified via interrupt when ready.
